# Mindstrike(心战)· PVP 猜招对决 — 局域网联机版

2 人 PVP 回合制猜招游戏: 双方在**各自的电脑/手机上**同时秘密出招、**每回合 2 秒时限**、
**1 滴血、命中即 K.O.**、整场 **BO3**, 能量无上限; 对局内置**程序实时合成的紧张鼓点 BGM**。

> 核心玩法 Demo 原为同屏版(选择容易被看到), 现改造为**双端联机版**:
> 每台设备只显示自己的出招卡片与按键, 对方选项完全保密; 锁定后统一揭示 ——
> 通过**双方小人的头顶对话框 + 动作**(蓄力/挥击/举盾/发呆)区分。
> 界面截图见 [preview/](preview/), 全部为新界面(双人小人对战场)。

## 如何联机(本地网络 · 零安装依赖 · 一键启动)

**最简单: 双击启动文件, 不用碰终端**

| 房主电脑系统 | 双击这个文件 |
|---|---|
| macOS | `启动联机.command` |
| Windows | `启动联机.bat` |

双击后会自动启动服务器, 并**自动打开浏览器**进入游戏(就绪后约 1 秒)。
弹出来的终端窗口**不要关**(那是服务器本体, 关掉=服务器停止);
结束游戏后回到该窗口按 `Ctrl+C`, 或直接关窗。

> 前提: 房主电脑装有 Node.js(https://nodejs.org 下载 LTS 版);
> 首次运行若 macOS 提示"无法打开", 右键该文件 → 打开 一次即可。
> 启动时若系统询问"是否允许接受网络连接", 选**允许**(好友才能连进来)。

终端方式(与双击等价, 想自定义端口时用):

```bash
cd "Mindstrike"
node server.js            # 或 PORT=9000 node server.js
```

启动后终端会打印地址, 例如:

```
✓ 本机(这台电脑)打开:   http://localhost:8765
✓ 局域网好友(同一Wi-Fi)打开: http://192.168.1.5:8765
```

1. **房主**浏览器打开本机地址(双击启动的话已自动打开), 点 **🌐 联机对战** → 进入准备房间;
2. **好友**在浏览器打开 `http://房主IP:8765`(同一 Wi-Fi/局域网), 同样点 **联机对战** 加入;
   - 手机也可以(同一网络下直接访问该地址, 支持触摸点卡片);
   - 房间地址会在房主准备界面显示, 方便复制发给对方;
3. 双方在准备房间把 5 个动作**改成自己顺手的按键**(各自电脑各自改), 都点 **准备就绪** 即开战。

**房主踢人**: 房主=先进房的人(座位标"房主")。对手卡死/赖着不走时, 房主可以在
**准备房间**点对方座位上的 **🚫 移出**, 或在对局顶栏点 **🚫**(对局中踢人=本局取消回房);
被移出的人会收到提示并回到主菜单, **60 秒内无法重连**, 空位立刻可让新人加入。

其他提示:

- 想用别的端口: `PORT=9000 node server.js`; 只允许本机: `HOST=127.0.0.1 node server.js`;
- 演示/测试加速: `MS_SPEED=5 node server.js`(5 倍速);
- Windows 首次运行若好友连不上, 请在防火墙中允许 Node.js 通过"专用网络"。

## 远程联机(两台电脑不在同一网络)

`server.js` 已监听所有网卡(0.0.0.0),所以只要让"公网能访问到房主电脑的 8765 端口"即可远程玩。
游戏协议对网络延迟很宽容(2 秒出招窗口 + 250ms 迟到宽限),跨省/跨国都能打。按推荐顺序:

**① Cloudflare 临时隧道(最省事 · 免注册 · 地址每次会变)**

```bash
# 房主: 先启动服务器(node server.js 或双击 启动联机.command),
# 再另开一个终端:
brew install cloudflared        # macOS; Windows 去 cloudflare 官网下 cloudflared.exe
cloudflared tunnel --url http://localhost:8765
```

把终端打印的 `https://xxxx.trycloudflare.com` 发给好友即可(无需装任何东西)。
适合"约局即用"; 隧道关了地址就失效。

**② Tailscale 组网(固定 IP · 最适合固定车队)**

两台电脑都安装 https://tailscale.com/download 并登录(同账号或互相邀请)。
房主启动服务器后执行 `tailscale ip -4` 得到形如 `100.x.x.x` 的组网 IP,
好友直接访问 `http://100.x.x.x:8765`。IP 长期不变, 穿越 NAT/防火墙成功率高。

**③ 路由器端口转发(需要宽带是公网 IP)**

路由器把 TCP 8765 转发给房主电脑 → 好友访问 `http://公网IP:8765`。
大内网(CGNAT)宽带此方案无效。

**④ 部署到公网服务器(双方都不用依赖房主电脑在线)**

server.js 本身就是一个可用的中继服务器: 把它上传到任意公网主机(Render / Railway /
Replit / 轻量云服务器均可, 零依赖, `node server.js` 即跑), 然后**两位玩家都访问该公网地址**:
先到的人点"联机对战"建房, 后到的人加入, 就绪开打。房主电脑关机也不影响。

## 如何单人练习(不需要服务器)

直接双击 `index.html`(纯静态), 或 `python3 -m http.server 8000` 后打开 ——
点 **🤖 单人练习 · 对电脑** 即可用同一套新界面熟悉规则与改键(此模式电脑自动出招)。

> 从浏览器直接打开文件时, "联机对战"按钮不可用(需要房主先启动 server.js)。

## 操作

在准备房间点 **改键** 后按下新键即可(每台电脑独立记忆自己的键位, 默认如下表):

| | 蓄力 ⚡ | 小攻击 🗡️ | 小防御 🛡️ | 大攻击 💥 | 大防御 🔰 |
|---|---|---|---|---|---|
| 蓝方(房主默认) | `1` | `2` | `3` | `4` | `5` |
| 红方(挑战者默认) | `6` | `7` | `8` | `9` | `0` |

- 每回合**倒计时 2 秒**内按自己的键或点击自己一侧的卡片; **只显示自己的 5 张卡片**,
  看不到对方的按键/选择(对方头顶只会出现"思考中/已锁定");
- **表情互动**: 对战界面左侧有表情栏(😂😭😡👍😮…), 任何时刻点击即发:
  弹出 1 秒、冷却 1.5 秒, 带音效, **双方屏幕同步弹出**(经服务器转发, 局域网/远程都行);
- 窗口结束双方统一揭示: 各自头顶出现对话框(如 🗡️ 小攻击), 小人会做出对应动作
  (蓄力聚气 ⚡ / 突进挥击 / 举盾格挡 / 发呆 💤), 挡下与命中都有火花/受击反馈与音效;
- 超时未出招 = **发呆**: 不获得能量、无法防御, 会被打;
- 出招窗口最后 0.7 秒计时条变红, 心跳鼓点自动加速加压。

## 规则

- 开局: 双方 1 滴血、0 能量。蓄力 +1 能量,**没有上限**; 能量在小局结束时清零。
- 动作: 小攻击耗 1 能量; 小防御免费(只挡小攻击);
  大攻击耗 3 能量; 大防御耗 1 能量(挡大 + 小攻击)。
- 双方同时出攻击: **同级(小vs小 / 大vs大)攻击相撞抵消**, 无事发生, 能量照常消耗;
  **大攻击 vs 小攻击 → 大攻击直接压过, 出小攻击的一方被斩杀 K.O.**(不会同归于尽)。
- 攻击打在防御上: 盾面火花粒子爆发 + 格挡音效(大攻击被大防御挡下更重); 被斩杀方倒地扬尘。
- 攻击未被挡下即命中 → 被命中方 **K.O.**, 输掉本小局。
- 整场 **BO3**: 先赢 2 个小局者获胜; 结束后**胜者电脑奏胜利凯旋乐, 败者电脑奏落幕挽歌**, 双方点"再来一局"自动开新场(比分清零)。
- 补充设定(沿 Demo): 单小局超过 **40 回合**无人阵亡 → 判平重开; 服务器为权威时钟,
  中途离开/断线 → 对局取消回到准备房(对手会收到提示)。

## 更换素材(小人 / 战斗背景)

默认的小人是纯 CSS 绘制的占位角色(蓝方斗士/红方斗士), 支持直接换图:
在项目里建 `素材/` 文件夹, 放入 `p0.png`(蓝方)与 `p1.png`(红方)
(支持 png / svg / webp / gif / jpg, 会自动优先生效), 页面加载后即替换;
图片会随角色整体移动/挥击/倒地(建议画成正面/侧面全身像, 高约 150px 比例)。

**战斗背景**: 把背景图命名为 `bg.jpg`(或 bg.png / bg.webp)放入 `素材/`,
会自动作为对战舞台背景, **cover 全屏自适应**(不拉伸、手机/宽屏都自动裁剪适配);
程序化的星空/月亮/地面会自动隐藏并叠加暗化层, 保证小人、对话框、计时条清晰。

换素材后刷新页面即生效(图片已设为 no-cache, 无需清缓存)。
对局内 BGM 目前是 WebAudio 实时合成的鼓点(零素材依赖, 见 sfx.js 注释中如何替换为音频文件)。

## 声音

- 主菜单音乐: `音效/游戏初始背景音乐.mp4` 循环;
- 对局内: 紧张鼓点 BGM + 出招/锁定/命中/格挡/相撞/K.O./胜负提示音(WebAudio 合成);
- 右上角 **♪ 声音: 开/关** 可随时开关(记忆在浏览器里)。
- 浏览器自动播放限制: 首次进入页面后任意点击一下即可出声。

## 代码结构

```
server.js   零依赖联机服务器(Node 内置模块): 静态托管 + 房间/权威回合时钟/长轮询 API
启动联机.command/.bat  一键启动(Mac 双击 .command / Windows 双击 .bat): 启动服务器并自动打开浏览器
index.html  界面 + 样式(菜单 / 准备房间 / 双人小人对战舞台 / 覆盖层)
game.js     纯逻辑核心(结算/能量/相撞判定, 浏览器与 Node 共用, 未改动)
sfx.js      WebAudio 声音引擎(对战 BGM 合成器 + 音效 + 主菜单音乐控制)
app.js      客户端逻辑(联机轮询/改键/AI 练习/对战演出编排)
音效/       音频素材(主菜单音乐)
test/       测试(见下)
preview/    新界面截图
```
